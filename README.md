# Endless NFT Tagger 

**Collaborative on-chain tagging & file attachments for Endless ecosystem NFTs**

This repository contains the **Aptos Move module** for on-chain NFT tagging and file attachments system. It allows community-driven tagging (e.g., #art, #pfp, #generative) and attaching files directly to NFT objects in the Endless Protocol ecosystem.

## Project Overview

- **Frontend Demo**: [https://endless-nft-tagger-frontend-stwp.vercel.app](https://endless-nft-tagger-frontend-stwp.vercel.app) (deployed on Vercel)
- **Frontend Repository**: [https://github.com/Bellafuria/endless-nft-tagger-frontend-](https://github.com/Bellafuria/endless-nft-tagger-frontend-)
- **Full Project Description**: [Supporting Document](https://docs.google.com/document/d/1voavGDnxxgbrnV6ouGgkSxFpGALaOJQ-pwn458trDEY/edit?tab=t.0)

This module is part of the submission to the **Endless Ecosystem Creative Proposal Competition** (Fill a Gap category).

## Features

- Add/remove community tags to any NFT object
- Attach files (e.g., cover.jpg, additional metadata) on-chain
- View current tags and attachments
- Designed for integration with Luffa and other Endless apps
